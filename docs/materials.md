# 素材清单与要求

本文列出做一首「AI 翻唱 MV」需要准备的全部素材、质量门槛和目录组织方式。

## 一、音色训练素材（一次性）

用于训练 RVC 音色模型，决定最终音色像不像、有没有杂音/爆音。

### 硬性要求

| 项目 | 要求 |
|---|---|
| 数量 | **20–60 首**（推荐 30–40） |
| 类型 | **单人独唱**，不要合唱、对唱、多人版 |
| 版本 | 录音室原版，不要现场/Live/翻唱/消音版 |
| 格式 | **FLAC 无损** 优先；至少 320k MP3 |
| 采样率 | 44.1kHz / 48kHz |
| 总时长 | 1.5–4 小时（过少不穩，过多会稀释音色） |
| 人声状态 | 干净、无严重修音、无电音、无和声堆叠 |
| 语言 | 以目标歌曲语言为主（中文歌用中文素材） |

### 质量自查

- [ ] 每首都能正常播放、无损坏
- [ ] 没有 128k/192k 低码率文件混入
- [ ] 不是「伴奏/纯音乐/消音版」
- [ ] 不是多人合唱（文件名含 `、`、`&`、`×` 或多人名需排除）
- [ ] 不要用音源分离后的「人声」当训练素材（分离残留会变成杂音）

### 目录结构

```
data/train/
├─ 歌手 - 歌名1.flac
├─ 歌手 - 歌名2.flac
├─ ……
└─ 歌手 - 歌名30.flac
```

### 命名建议

统一 `歌手 - 歌名.flac`，方便脚本与人工核对。不要用特殊符号（`（）`、`【】`、空格过多）。

## 二、目标歌曲素材（每首一份）

| 素材 | 必需 | 说明 |
|---|---|---|
| 原唱音频 | ✅ | FLAC 优先，至少 320k MP3；必须与原版一致（注意版本时长） |
| 官方伴奏 | 推荐 | FLAC/320k；没有则由流水线用 BS-Roformer 分离 |
| 歌词 LRC | 推荐 | 有精确时间轴；没有则用 `scripts/audio/get_lrc_qq.py` 抓取 |
| 歌曲信息 | ✅ | 歌名、原唱、时长（秒）、BPM/风格、主题关键词 |
| 是否需要解说 | ✅ | 默认「否」，只放歌词字幕 |

### 注意：版本一致性

同一首歌常有多个版本（专辑版/现场版/混音版/消音版），**原唱、伴奏、LRC 必须属于同一版本**，否则：

- 时长对不上 → 音画不同步
- 歌词时间轴错位 → 字幕漂移
- 混音后结构与原版不同 → 听感不对

**核对方法**：原唱与伴奏时长差 < 0.5s，LRC 末句时间 ≤ 歌曲时长。

### 目录结构

```
data/<slug>/
├─ original.flac       # 原唱
├─ instrumental.flac   # 官方伴奏（可选）
└─ lyrics.lrc          # 歌词时间轴（可选）
```

## 三、MV 交付包（由 GPT 生成）

每首歌一个目录，必须 4 个文件：

```
packs/<slug>/
├─ 逐镜提示词.json
├─ 运镜时间轴_24fps.json
├─ style_guide.md
└─ README.md
```

规范见 [`packs/schema/pack-schema.md`](../packs/schema/pack-schema.md)，
生成方法见 [`guide-gpt-pack.md`](guide-gpt-pack.md)。

## 四、可选素材

| 素材 | 用途 |
|---|---|
| 参考图/参考 MV 截图 | 告诉 GPT 想要的画面风格 |
| 禁用元素清单 | 如「不要出现现代建筑/人脸特写」 |
| 片头声明文案 | 默认「原唱：X · AI 合成：双笙音色 · 个人自用 · 非商用」 |
| 字体 | 默认 MaShanZheng（OFL）；可替换 |

## 五、最终目录结构总览

```
project/
├─ data/
│  ├─ train/                    # 训练素材（一次性）
│  └─ <slug>/                   # 目标曲素材
├─ models/rvc/<voice>_e100.pth  # 训练好的音色模型
├─ packs/<slug>/                # GPT 交付包
├─ remotion/public/mvimages/<slug>/  # 逐镜图片 S01.png…
├─ remotion/props/<slug>.json   # 合成用时间轴
├─ output/<slug>/               # 成品 MP3 / MV
└─ configs/songs/<slug>.json    # 歌曲配置
```
