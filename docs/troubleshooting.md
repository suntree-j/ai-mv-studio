# 常见问题排查（Troubleshooting）

## 音频

### 副歌/高音爆炸音
- **原因**：用「原曲 − 伴奏」相位抵消做人声输入；或训练/转换素材质量差
- **解决**：必须用 BS-Roformer 分离人声；训练只用高质量原曲；试 e60/e80/e100 不同检查点

### 句首爆音
- **原因**：单遍动态 loudnorm 在句首做了 +20dB 以上提升
- **解决**：先静态增益到目标响度，再统一 `loudnorm` 一次；或最后统一 `-14 LUFS` 一次

### 回响/人声糊
- **原因**：分离伴奏里有人声残留，混音后产生梳状感
- **解决**：优先官方伴奏；没有时用 BS-Roformer，并检查伴奏轨是否有残留人声

### 声音发闷/杂音底噪
- **原因**：训练数据含 128k/192k 低码率、或分离残留
- **解决**：训练集只用 FLAC/320k 原始曲；不要用分离人声训练

### 音色不像
- **原因**：训练集太少（<20 首）、混入合唱/翻唱、或音色本身差异大
- **解决**：30–40 首同歌手独唱；不要混入其他人声；必要时按歌 fine-tune

### 时长与原版不一致
- **原因**：原唱/伴奏/LRC 不是同一版本
- **解决**：核对三者时长，统一同一版本；不要用「消音版」当原唱

## MV / 出图

### Flux 出图发白/几乎空白
- **原因**：缺 `ModelSamplingFlux` 节点，或 cfg 与 Flux 不匹配
- **解决**：用仓库 `gen_flux.py` 的默认工作流（含 ModelSamplingFlux，cfg=1.0，steps=20）

### 出图 OOM
- **原因**：与 RVC 转换/训练同时占用 GPU
- **解决**：串行执行；出图分辨率降到 1344×768；关掉其他显存占用

### 画面风格不统一
- **原因**：每镜 prompt 风格前缀不一致
- **解决**：让 GPT 为全部镜头加统一风格前缀；抽帧比对后重出问题镜头

### 画面出现文字/印章/人脸
- **原因**：prompt 未排除
- **解决**：negative_prompt 加 `text, letters, Chinese characters, seal, watermark, close-up face, facial features`；重出该镜

### 歌词超出画面/被截断
- **原因**：字太长或字号固定
- **解决**：本仓库 `PackMV` 已支持按短语断句、自动分列、字号自适应；确认使用的是最新版组件

### 歌词右到左 / 顺序不对
- **原因**：竖排用了 `row-reverse`
- **解决**：升级到最新 `PackMV.tsx`（列从左到右）

### 歌词与背景同色看不清
- **原因**：固定颜色
- **解决**：`build_mvprops.py` 会计算每镜亮度 `lum`，组件按亮度选深墨/米白并加描边阴影

### 时间轴对不上视频
- **原因**：帧数计算错误或镜头不连续
- **解决**：用 `guide-gpt-pack.md` 的校验脚本检查；`total_frames = round(时长×24)`

### Remotion 渲染报错
- 确认 `npm install` 完成、props 中的图片文件都存在
- 确认 `--props` 路径正确、JSON 合法
- 报错含 `delayRender` 通常字体加载失败：检查 `public/fonts/` 字体文件

## 环境

### RVC 训练脚本循环导入
- **原因**：`python train/train.py` 触发模块名冲突
- **解决**：用 `runpy.run_path` 方式（见 `train_pipeline.sh`）

### ComfyUI 缺依赖（yaml 等）
- **解决**：`pip install -r requirements.txt`，国内可加清华镜像重试

### 中文路径异常
- **解决**：素材/输出路径尽量用 ASCII；脚本已尽量使用相对路径
