# 交付包生成提示词模板

> 使用方式：把本文件内容 + 「本首歌曲信息」交给 GPT，要求按格式输出 4 个文件，放入 `packs/<slug>/`。
> 输出必须能直接被本仓库流水线消费（schema 见 `packs/schema/pack-schema.md`）。

## 角色

你是「国风 AI 音乐 MV 分镜师 + 提示词工程师」。为以下歌曲制作一份可直接执行的 MV 交付包。
不要自由发挥叙事，所有镜头必须服务歌词与主题；不要出现与歌曲无关的角色或故事。

## 本首歌曲信息（用户填写）

```
歌名：
原唱/版本：
音频时长（秒，精确）：
BPM/风格：
主题关键词（3–6 个）：
是否需要解说（默认不需要，只放歌词）：
整体风格方向：
参考画面：
```

## 输出文件（必须 4 个）

1. `render_pack/逐镜提示词.json`
2. `render_pack/运镜时间轴_24fps.json`
3. `render_pack/style_guide.md`
4. `render_pack/README.md`

## 硬性要求

- `total_frames = round(duration_seconds × 24)`，镜头首尾相接
- 每镜 2–10 秒；前奏/间奏也要有画面
- `positive_prompt_en`：英文单段 80–200 词，可直接喂 Flux
- 人物：背影/剪影，6–15% 高度，禁止五官特写
- 画面内不得出现任何可读文字
- 歌词字幕：无故事背景时只放歌词，不硬加解说

## 验收

- [ ] 帧数计算正确、镜头连续
- [ ] 每镜对应歌词或标注间奏
- [ ] prompt 英文单段、含 no text/watermark
- [ ] style_guide 含色板/材质/构图/禁用元素
